# Этап 2. Файл настроек config.json и общая форма в public/

## Цель
Одна общая форма заявки в папке `public/`. Всё, что зависит от ниши, берётся из `public/config.json`.
Чтобы сменить нишу, нужно скопировать готовый файл настроек на место `config.json`. Код при этом не трогаем.

## Ограничения (из PROJECT.md)
- Без библиотек и фреймворков: чистые HTML, CSS и JS, как на Этапе 1.
- Папку `furniture/` не менять и не удалять. Она остаётся как образец Этапа 1.
- Не вписывать секреты, токены и ключи ни в какие файлы.
- Отправку заявок и уведомления не делать: это отдельный этап.

## Структура config.json
```json
{
  "companyName": "Мастер Мебель",
  "title": "Сборка и ремонт мебели",
  "subtitle": "Заполните форму и приложите 1–5 фото. Мастер перезвонит и назовёт точную цену.",
  "colors": {
    "primary": "#2b6cb0",
    "accent": "#ed8936"
  },
  "contacts": {
    "phone": "+7 900 000-00-00",
    "telegram": "https://t.me/example",
    "whatsapp": "https://wa.me/79000000000",
    "max": ""
  },
  "services": [
    { "name": "Сборка шкафа", "priceFrom": 1500 },
    { "name": "Ремонт дверцы / петель", "priceFrom": 500 }
  ],
  "notifications": {
    "telegram": true,
    "max": false,
    "whatsapp": false
  }
}
```
Правила:
- Ссылки на мессенджеры указываются полностью и начинаются с `https://`. Пустая строка значит, что мессенджер не показывается.
- `priceFrom` — целое число в рублях.
- Контакты в обоих примерах заглушки: `+7 900 000-00-00` и ссылки с `example`.
- `notifications` на этом этапе только хранится в файле. Код эти значения не использует.

## Наполнение примеров
- `furniture.json` («Сборка и ремонт мебели»): 6–8 услуг, например сборка шкафа, кухни, кровати, ремонт дверец и петель, замена фурнитуры, перетяжка стула. Цвета синий и оранжевый.
- `windows.json` («Ремонт окон»): 6–8 услуг, например регулировка окна, замена уплотнителя, замена ручки, ремонт фурнитуры, замена стеклопакета, москитная сетка. Цвета зелёный и жёлтый либо другая заметная пара, не такая, как у мебели.
- Цены реалистичные и с пометкой «от».

## Поведение страницы
1. **Загрузка настроек.** `fetch('config.json', { cache: 'no-cache' })` при запуске.
   - Если файл не загрузился или в нём ошибка, вверху показать понятное сообщение: «Не удалось загрузить настройки (config.json). Если вы открыли файл двойным щелчком — запустите проверку по инструкции в README.» Форма при этом остаётся рабочей, с текстами по умолчанию, которые прописаны в HTML.
   - Если какого-то поля нет, используется значение по умолчанию, страница не ломается.
2. **Тексты.** `companyName` выводится в шапку, `title` в `<h1>` и в `document.title`, `subtitle` в подзаголовок.
3. **Цвета.** В CSS завести переменные `--primary` и `--accent` (по умолчанию текущий синий `#007aff` и оранжевый). JS подставляет значения из настроек, только если они в формате `#rgb` или `#rrggbb`, иначе остаются цвета по умолчанию.
   - `--primary`: кнопка, рамка поля в фокусе, шапка.
   - `--accent`: цена выбранной услуги и ссылки в подвале.
   - Текст на кнопке и в шапке должен оставаться читаемым. Белый текст на `--primary` допустим, поэтому примеры цветов выбирать достаточно тёмные.
4. **Шапка.** Название компании и телефон кликабельной ссылкой `tel:` (в ссылке только `+` и цифры).
5. **Подвал.** Телефон и ссылки на заполненные мессенджеры (Telegram, WhatsApp, MAX) с `target="_blank" rel="noopener"`. Текущая надпись «Прототип: заявка не отправляется…» остаётся.
6. **Выпадающий список услуг.** Новое поле «Услуга» перед полем «Опишите проблему».
   - Первый пункт «Выберите услугу» с пустым значением.
   - Пункты в виде «Сборка шкафа — от 1 500 ₽». Цену форматировать через `toLocaleString('ru-RU')`.
   - Под списком строка «Ориентировочная цена: от 1 500 ₽ (точную цену назовёт мастер)». Она появляется при выборе услуги и выделена цветом `--accent`.
   - При проверке нужно сообщение «Выберите услугу.» с подсветкой поля и фокусом, по тому же образцу, что у телефона.
   - Если `services` пустой или отсутствует, поле скрыть и не требовать.
7. **Безопасность.** Значения из config выводить только через `textContent` или `setAttribute`, без `innerHTML`. Ссылки мессенджеров принимать, только если они начинаются с `https://`.
8. Вся логика Этапа 1 должна работать как раньше: фото 1–5 с превью и удалением, проверка телефона, проверка описания.

## Раздел в README
Коротко и простыми словами:
1. Как сменить нишу: скопировать `public/configs/windows.json` и вставить на место `public/config.json`, затем поправить название, телефон, ссылки, услуги и цены.
2. Как проверить на компьютере: открыть папку `public` через расширение VS Code «Live Server» (кнопка «Go Live»). Запасной вариант: `python -m http.server 8000` в папке `public` и адрес `http://localhost:8000`.
3. Предупреждение: двойной щелчок по `index.html` не подходит, потому что браузер не даст прочитать настройки.

## Готово, когда
- В `public/` есть все файлы из таблицы, `furniture/` не изменена.
- После замены `config.json` на `windows.json` меняются название, заголовки, цвета, контакты и список услуг с ценами. Код при этом не правится.
- Сломанный или отсутствующий `config.json` даёт понятное сообщение, а не белый экран.
- Проверки Этапа 1 и новая проверка услуги работают.
